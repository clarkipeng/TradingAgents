The backend is the agent’s world

Yes: agents ask our temporal gateway for every external datum. Permitted collectors populate the backend separately. A replay run reads only sealed evidence—never the live internet.

Critical distinction

Store every permitted response the agent may see, not “the whole web.” The source registry defines that universe and its legal/operational limits.

Which traffic is allowed?

One-way external ingress; one agent-facing gateway

Replay prohibition: the gateway has no collector/network escape hatch in replay mode. A missing record is an explicit evidence-missing result, not a fresher answer.

Control plane

What may exist

Source registry, credentials reference, poll cadence, timestamp policy, access classification, retention/license, tool schemas, and scenario definitions.

The policy layer prevents “crawl anything” from becoming an unbounded or unsafe system.

Evidence plane

What was known

Immutable raw artifacts plus versioned metadata. Every response retains content hash, source, observed time, available time, and confidence.

Raw evidence is authoritative; text/vector indexes are rebuildable derivatives.

Evaluation plane

What the agent did

Virtual-time tool traces, model configuration, cited evidence, scorecards, and separately stateful action simulations.

A market quote is evidence. A fill is a simulator policy result.

Capture and replay are deliberately different

The gateway always fronts the agent; its mode determines what can happen behind it

ModeOn a requestExternal accessRequired writeWhy it exists
liveServe approved fresh collector/vendor dataCollectors onlyOptional tracePreserves current production behavior

replaySelect the latest eligible stored evidenceForbiddenRun trace onlyBacktesting, regression tests, audit

`available_at ≤ scenario.as_of` is enforced by the gateway, not trusted to an agent prompt. Captured errors are replayed too; history must not improve merely because a source is reachable today.

Storage model

Three stores, distinct jobs

Raw object store

Content-addressed WARC/WACZ, HTTP, JSON, PDFs, exports, screenshots. S3-compatible; local filesystem/MinIO initially.

Metadata/provenance database

Postgres first: artifacts, evidence versions, request snapshots, sources, policies, scenarios, runs, action events.

Derived retrieval indexes

Postgres full text first; optional external search/vector store later. Rebuildable and never the lone source of truth.

What an agent-visible record means

Evidence is a version, not a URL

{
  "tool": "research.search",
  "request": {"query": "Fed rate decision"},
  "response": {"results": []},
  "artifact_hash": "sha256:…",
  "source_url": "https://…",
  "source_published_at": "optional claim",
  "observed_at": "2025-05-07T13:58:01Z",
  "available_at": "2025-05-07T13:58:04Z",
  "confidence": "exact | reconstructed",
  "connector_version": "…"
}

Exact replay uses a captured request/response snapshot. Historical corpus search supports new queries over versions available at time T, but records its own ranking algorithm/version rather than claiming third-party historical ranking.

Minimal-negative integration

TradingAgents changes only at data boundaries

Retained exactly as-is in default live mode

  • LangGraph agent topology, prompts, structured output, reports, memory, checkpointing.
  • Existing public tool names and configured vendor routing.
  • Live output shape and error semantics when no temporal context is present.

Additive adapter responsibilities

  • Wrap the vendor-routing boundary once rather than edit every analyst.
  • Move direct Reddit, StockTwits, and Polymarket retrieval through the same gateway.
  • Add an optional run context and sidecar trace; do not rewrite existing reports.
  • Introduce portfolio/fill simulation later as an independent action environment.
